# 2026-11-20 代码审查与修复

基于 `f707574` 检查采样、流量记账、SQLite、配置、更新、导出和平台交互。以下是本轮工作区修改，不代表穷尽所有缺陷。

## 已修复的问题

| 问题及触发条件 | 修改 |
| --- | --- |
| macOS 进程名以 `tcp` / `udp` 开头时被当成连接行，后续连接继承前一个进程的 PID | 只将完整协议标记和连接分隔符组成的行识别为连接；覆盖 `tcpdump`、`udp-client`、`tcp4 helper` |
| UDP 的通配端点 `*:*` 被当成回环，物理网卡上的这部分流量漏计 | 通配地址不再等同于回环；按 IP 地址类型识别 IPv4、IPv6 及映射回环 |
| macOS 应用缓存只用 PID，PID 被复用后继续沿用旧路径；失败身份可能永久缓存 | 使用进程启动时间与名称校验缓存，未解析到路径时允许重试；清理缓存使用 HashSet |
| `openpty` 的描述符没有 close-on-exec，启动其他子进程可能继承终端端点，延迟 EOF 和退出 | 两个描述符设置 `FD_CLOEXEC`；配置失败交由 File 自动关闭，检查 termios 配置结果 |
| 常驻图标加载线程调用 Cocoa 时没有 autorelease pool | 每次图标加载建立并释放独立 pool，清理临时 Cocoa 对象 |
| macOS 数据库阻塞后连续消费积压帧，按消费时刻计算速率会改变时间间隔 | 读线程为每帧记录 Instant；统一实际 nettop 采样间隔与对外 interval。管道回退模式的源输出缓冲仍有限制 |
| UI 不消费时，后台每次发送完整 Snapshot，队列可能持续增长 | 改为只保留最新快照；采样线程结束时清空旧速率并显示错误 |
| 保存设置和 LaunchAgent 会直接截断旧文件；UTF-8 BOM 会吞掉首项配置 | 同目录临时文件写完并 sync 后替换；公共文件写入 helper；配置兼容 BOM，写入错误记录日志 |
| 同一分钟重复导出覆盖已有 CSV，失败可能留下半截文件 | 临时文件完成后以不覆盖方式提交，重名自动加数字后缀；空库不创建 CSV |
| 一份损坏恢复日志会阻止后续有效日志恢复，异常时间戳还可能使采样线程崩溃 | 逐文件继续恢复，保留损坏文件并显示错误；先校验时间戳，保留原有恢复幂等标记 |
| 非法更新版本被当作“已是最新”；构建元数据参与了版本新旧比较 | 非法版本报错，使用 SemVer precedence 比较 |
| 下载文件名取自 URL，查询串会改变扩展名，部分路径字符还可能逃出目标目录；出错残留 `.part` | 验证版本与 HTTP(S) 地址，使用平台固定安装包名；独立临时文件在错误时清理，校验 SHA256 后提交，保留已有有效安装包 |
| 更新线程创建失败会 panic，下载入口可重复启动，macOS `open` 子进程不回收 | 线程创建返回可见错误，下载增加忙状态保护；macOS 等待 `open` 命令完成并检查退出状态 |
| 多应用累计及部分总量相加在 u64 边界会溢出 | 统一使用饱和加法；判断是否有流量时分别判断两个方向 |

同步整理了与实现不符的应用标识、设置格式等注释；新增 helper 的依赖 `tempfile` 和 `url` 已存在于原锁文件中，本轮没有升级第三方包版本。删除了普通采样单测对全局环境变量的修改，避免并行测试串扰。

- 新增回归首先复现 4 个失败：进程名前缀导致归属错误、物理接口通配 UDP 漏计、PTY 未设置 close-on-exec、跨应用累计溢出。
- 修复后 `cargo test --workspace --locked`：163 通过，3 个原生测试仍默认忽略；新增 14 项自动化测试。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`、格式检查和 `git diff --check` 通过。
- 下载测试使用本机临时 HTTP 服务，验证带查询串的网址、同版本重复下载、校验失败、连接中断、非法版本路径和非法 hash；不接触真实更新服务。
- 真实 nettop 测试：IPv4 / IPv6 各传输 8 MiB 本机回环数据，均计为 0；间隔约 1 秒，采集器在退出时被回收。

## 范围与使用

本轮没有改变代理跨帧归属算法、macOS 菜单栏排序或 Windows 任务栏挂接策略。原有 nettop 短连接采样丢尾、代理字节部分留在代理名下，以及菜单栏空间不足时折叠的限制仍然存在；具体见此前 macOS 验证记录。没有重新声明这些问题已解决。

新版应用在 `dist/Tramoing.app`，安装镜像为 `dist/Tramoing-0.1.0.dmg`。正在运行的旧进程不会自动加载新代码，需要从应用内退出后再启动新版。本轮不修改用户的历史库、系统代理或登录项配置；原生测试写入独立临时目录。

本轮日志保存在被 Git 忽略的 `target/code-audit/`。
