# 2026-11-20 紧凑宽度与自定义显示颜色

## 宽度

Windows 保留原来的 Segoe UI 12px 字号，只收紧列间距和内边距：

| 显示内容 | 原宽度 | 新宽度 |
| --- | ---: | ---: |
| 网速 | 44 | 40 |
| CPU / GPU | 64 | 58 |
| 网速与性能（含 4px 组间距） | 114 | 102 |

单位为逻辑像素，总宽减少约 11%。第一版压缩到 96 时，截图暴露出速率单位紧贴 CPU/GPU、短百分比离标签太远的问题。本次为两组加入 4px 明确留白，性能标签与数值之间保留 3px 列间距；网速仍右对齐，百分比改为左对齐。`0%`、`100%`、`--%` 和速率单位切换不会让标签移动。

macOS 把箭头、CPU / GPU 标签与数值之间的普通空格替换为窄空格，保留 9.5pt 字号、行高和基线。实际原生尺寸需在 Mac 上复核，本轮未在 Windows 上模拟 AppKit 渲染。

## Windows 拖动排序

- 按住网速或 CPU/GPU 区域拖过另一组的中点，即可预览交换前后位置，松开后保存。
- 竖向任务栏使用相同规则交换上下位置；CPU 与 GPU 继续作为一个双行区块。
- 轻微鼠标抖动仍按点击处理；一旦开始拖动，即使回到起点也不再触发点击打开面板。
- 拖回原处、移出控件后松开、丢失鼠标捕获或系统取消拖动，均恢复原顺序。
- 实时采样刷新不会打断拖动；禁用其中一组、尺寸或 DPI 变化会取消当前拖动。
- 「设置 → 任务栏性能 → 显示顺序」也可选择「网速在前 / 性能在前」。配置键 `taskbar_performance_first=on` 表示性能在前，`off` 表示网速在前，默认 `off`；重启及关闭再启用性能均保留选择。
- macOS 已有原生拖动，本次不改它的排序行为。

## 两个平台共用的颜色设置

- CPU / GPU 颜色位于「设置 → 菜单栏性能」（macOS）或「设置 → 任务栏性能」（Windows）。
- 下载 / 上传颜色位于「设置 → 显示」。
- 选择「彩色」后显示颜色控件：点击色块打开选择器，也可直接输入 `#RRGGBB`；点击「默认」恢复随系统明暗切换的默认色。
- 自定义色应用到对应整行，互不影响。单色模式暂时忽略自定义色，切回彩色仍保留已保存的选择。
- 界面修改即时更新并保存；十六进制输入尚未完成或不合法时，不覆盖已有颜色。
- 旧配置缺少这些键时保持原来的默认配色。自定义颜色保存为固定 sRGB 值；`auto` 使用系统菜单栏/任务栏主题的默认值。

`settings.conf` 示例：

```ini
performance_color=on
tray_color=on
cpu_color=#FF8800
gpu_color=#A78BFA
download_color=#34D399
upload_color=#38BDF8
```

单独把某一项设成 `auto` 即恢复该项默认颜色。文件手动编辑后重启应用读取；界面调整无需重启。
