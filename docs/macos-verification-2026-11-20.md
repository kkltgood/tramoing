# 2026-11-20 macOS 原生验收与列表滚动修复

环境：Apple Silicon，macOS 27.0.1（26A434），Rust 1.89.0，Apple Command Line Tools。本轮基于 `de73483`，以下结果包含工作区内的滚动修复和测试辅助改动。

## 列表滚动修复

用户报告应用列表无法滚动。旧实现每帧写回偏移，只要当前帧位移没有变化，就执行 `snap_scroll` 吸附到最近整行。macOS 触控板的小幅事件之间会穿插空闲重绘帧；每次不足半行的移动都被吸回去。

使用真实 egui `Context` / `ScrollArea` 注入事件复现：60 Hz 重绘，每三帧输入一次 3pt 位移，共输入 60pt，旧实现最终偏移为 **0pt**。修复后偏移为 **60pt**，空闲 30 帧后保持不变，反向滚动回到顶部。

- 去掉逐帧整行吸附和强制覆盖偏移，由 ScrollArea 管理连续滚动。
- `TM_SCROLL` 只设置初始位置，自绘滚动指示条读取实际偏移。
- 回归还覆盖鼠标滚轮滚到 20 行列表底部，以及列表缩短为 3 行时清除越界偏移。
- 这些是输入事件回归，不代表已完成系统触控板的实际手势验收。

- 独立 bundle id 的演示 `.app` 成功启动；菜单栏两行数字持续更新，自身离屏渲染输出成功，箭头和数值可读。
