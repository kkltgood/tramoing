# 2026-11-20 Windows 任务栏 CPU / GPU

Windows 任务栏现在支持与 macOS 对应的 CPU / GPU 双行显示：上排 CPU，下排 GPU，位于网速旁边。入口为「设置 → 任务栏性能」，默认关闭。

## 使用

- CPU / GPU 总开关控制两行显示和独立采样线程。
- 刷新间隔为 1 / 2 / 5 秒，默认 2 秒。
- 彩色模式使用 CPU 蓝、GPU 紫；单色随 Windows 任务栏明暗主题切换。
- 点击性能区域打开设置，并回到设置列表顶部。
- 网速与性能开关独立，可以只显示性能。百分比固定宽度，未获得有效读数时显示 `--%`。
- Windows 托盘图标的悬停提示也包含 CPU / GPU 数值，演示模式标注「演示数据」。

继续使用已有配置项，不需要迁移设置：

```ini
performance_enabled=on
performance_color=on
performance_interval=2
```

## 采集与布局

`tm-windows/src/utilization.rs` 使用系统 PDH API，不启动子进程、不依赖 ETW 助手、不请求提权。通过 `PdhAddEnglishCounterW` 使用与系统语言无关的计数器路径。

- CPU：`\Processor Information(_Total)\% Processor Time`，覆盖所有处理器组的平均忙碌比例。
- GPU：`\GPU Engine(*)\Utilization Percentage`，按 LUID、物理设备和引擎编号合并各进程数值，再取最忙引擎。不同设备和引擎不相加，最终限制在 0–100%。
- CPU / GPU 使用独立查询，GPU 不支持不会使 CPU 读数失效。检查计数器状态和有限数值；动态实例缓冲不足时有限重试，无法打开的计数器每 30 秒重试。
- 首次采样只建立基线；关闭功能回收采样线程及 PDH 查询。沿用现有过期数据过滤和刷新间隔调整机制。

网速与性能共用一个原生任务栏子窗口和一份空间预留，避免多个窗口分别调整 Win10 按钮区。紧凑布局经截图反馈修正后，仅网速宽 40、仅性能宽 58、组间留白 4，总宽 102 个逻辑像素，保留 12px 字号。百分比靠左贴近标签，避免短读数与标签分离。横向并排；竖向任务栏宽度不足以并排、但足够容纳单组时上下排列。支持按住任一组拖动交换前后（竖向为上下）位置，松开后保存；拖出控件取消。绘制、拖动和点击命中使用相同布局。自定义颜色和本轮验证见 [配色与宽度记录](display-colors-2026-11-20.md)。

沿用逐像素透明背景、灰度抗锯齿、主题切换和 Explorer 重建后的重新挂接。Win11 的任务栏空间和布局限制与原网速显示相同；空间不足时给出提示，设置页和托盘悬停提示仍能查看数值。

## 验证

- 性能功能初版的联调工作区执行 `cargo test --workspace --locked --quiet`：169 项通过，3 项原生环境测试默认忽略。后续排版、配色、拖动排序及独立提交的验证结果见 [配色与宽度记录](display-colors-2026-11-20.md)。
- `cargo clippy --workspace --all-targets --locked -- -D warnings`：通过。
- 单独运行原生性能采集测试：本机实际读到 CPU 约 1.48%、GPU 约 2.30%，均为真实计数器读数。
- 单独运行任务栏原生生命周期测试：挂接、网速/性能点击区分、两组切换为单组后的尺寸恢复、子窗口销毁后的重建、禁用后移除均通过。
- 绘制测试覆盖 100% / 125% / 150% / 200% 缩放、明暗主题、独立配色、横向/竖向布局，以及 `0%`、`100%`、`--%` 切换时标签位置固定。
- 隔离的 debug 演示实例通过界面操作检查深浅主题、性能关闭/重新开启、单色、5 秒刷新，以及隐藏网速后保留性能。预览实例已退出，日志和该实例的设置位于 `target/windows-performance-review/`。

GPU 是否可用取决于驱动是否提供对应性能计数器（通常为 WDDM 2.x）。本轮未在 Win10 真实竖向任务栏或多 GPU 硬件上验收；对应布局及 GPU 合并逻辑由测试覆盖。macOS 原生界面未在本机重新运行。

Windows 安装包由 `packaging/windows/build.ps1` 生成到 `dist/Tramoing-0.1.0-setup.exe`，程序文件位于 `dist/windows/`。
