本次更新优化后台流量统计和图标缓存，并开始按系统和处理器架构提供四种独立安装包。

## 性能与可靠性

- 优化 1 分钟、5 分钟、1 小时统计和 10 分钟流量提醒的计算，减少后台重复扫描历史数据。
- 减少采样时重复生成和排序应用列表，以及图标缓存命中时的字符串分配。
- 图标、加载失败记录和待加载请求合计最多保留 256 项，避免长时间运行或图标加载缓慢时持续积压。
- 优化电脑长时间休眠后的历史过期处理，避免逐秒补齐整小时的空数据；历史缓冲区满后也不再触发额外扩容。
- 同一秒内同一应用的多条记录正确合并，保留大数值统计和过期扣减的准确性。
- 新增窗口边界、休眠恢复、大数值和图标缓存回归测试，以及可重复运行的性能基准。

本机 Windows 基准中，64 个应用、一小时历史，每轮采样与四种窗口查询的中位耗时从约 635 微秒降至 12 微秒，减少约 98%。该结果只衡量窗口计算环节，实际整机 CPU 和内存变化取决于应用数量、采样与界面使用情况。

## 下载与升级

请按系统和处理器选择安装包：

- Windows 10 / 11，Intel / AMD 64 位：`Tramoing-0.1.6-windows-x64-setup.exe`。
- Windows 11，ARM64（如 Snapdragon）：`Tramoing-0.1.6-windows-arm64-setup.exe`。
- macOS 11+，Apple Silicon（M 系列）：`Tramoing-0.1.6-macos-arm64.dmg`。
- macOS 11+，Intel：`Tramoing-0.1.6-macos-x64.dmg`。

每个安装包均附带 SHA-256 校验文件，`latest.json` 用于应用内更新。Windows 安装包包含同架构的主程序和采集助手，请通过安装包一起更新。已有配置和历史数据会保留。

在 Rosetta 或 Windows x64 模拟环境下运行的程序仍会选择 x64 更新包；需要切换到 ARM64 时，请手动安装对应版本。

**macOS v0.1.4 及更早版本首次升级到新版时，请下载并打开 DMG 手动安装，以迁移应用标识。** v0.1.5 及之后的版本可继续使用应用内更新。

Windows 安装包尚未进行代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证。
