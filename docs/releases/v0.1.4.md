本次更新修复 macOS 网络采集的高能耗问题，并增加应用置顶，方便持续查看关注软件的网速。

- 修复部分 macOS 版本中 `nettop` 因输入流持续报告 EOF 而空转的问题，降低 CPU 占用，保持每秒采样。
- 应用列表每行末尾增加置顶按钮。置顶项按选择顺序固定在前面，其他应用继续按流量排序。
- 置顶选择立即保存，重启后保留；实时、1 分钟、5 分钟和 1 小时视图共用置顶顺序。
- 置顶应用没有流量或已经关闭时仍保留零速率行；置顶数量超过展示上限时仍全部保留，可滚动查看。加载和采集异常时继续显示原有状态提示。
- 精简列表，移除应用名称、下载和上传的列标题及行末详情箭头；点击行主体仍可查看详情。
- 图钉采用小号细线轮廓和 15° 轻微倾斜，无常驻底板；支持鼠标、键盘操作及深浅色主题。
- 补充能耗、置顶顺序、设置保存和按钮交互的回归验证，并更新使用说明及界面截图。

Windows 10/11 x64 下载 `Tramoing-0.1.4-setup.exe`；macOS 11+（Apple Silicon / Intel）下载通用包 `Tramoing-0.1.4.dmg`。安装包均附带 SHA-256 校验文件，`latest.json` 用于应用内更新。

已安装的 macOS v0.1.3 可在应用内点击“更新并重启”，自动替换并重新打开，无需再次拖拽，设置和历史记录保留。

Windows 安装包尚未进行代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证，系统可能仍会显示来源或安全提示。
