本次更新新增 Windows 游戏悬浮窗，可在游戏上方用一行查看网速、CPU / GPU 使用率、温度和 FPS。悬浮窗默认关闭，需在“设置 → 游戏悬浮”中手动开启；显示、配色和采样控制独立于任务栏。

## Windows 游戏悬浮窗

- 所有指标横向排列，可分别显示或隐藏，并为下载、上传、CPU、GPU 和 FPS 设置颜色；温度沿用对应 CPU / GPU 配色。
- 支持调整字号和背景不透明度，按屏幕百分比定位，或解锁后直接拖动；锁定后鼠标穿透，不抢游戏焦点。支持保存显示器位置及负坐标，屏幕变化时调整回可见区域。
- 开关、位置和外观自动保存，重启后恢复上次设置。首次安装和旧配置升级均保持默认关闭；关闭后释放悬浮窗独立采集。
- 设置说明放在对应控制项附近，便于了解 FPS、温度、锁定和位置调整；组件下载、暂停或待安装时，关闭温度显示仍保留操作入口。

## FPS 采集与响应

- 通过配套管理员助手采集 DXGI / D3D9 Present 提交速率。先探测前台程序，获得有效帧数据后持续跟踪该进程直到退出，切换软件不改变已捕获目标。
- 有有效读数时显示 `FPS 数值`，无数据、过期或采集失败时显示 `FPS --`；不使用屏幕刷新率代替 FPS。
- 优化首次采样调度及事件交付，修复低帧率抖动、待配对事件积压和旧渲染链影响读数的问题；快速关闭、重开时不会重新显示旧请求的结果。
- FPS 统计的是程序提交帧的速率，不等同于最终显示或插帧后的帧率；Vulkan / OpenGL 暂不支持。悬浮窗适用于窗口化及无边框游戏，独占全屏不保证覆盖。

## 操作与性能

- 滑块和色盘拖动时即时预览，松手后合并保存；收起面板或退出时保存尚未提交的改动。
- 移动悬浮窗或切换锁定时复用绘制结果，减少重复绘制。
- 关闭悬浮窗或切换温度采集时，由后台完成正在进行的硬件查询，界面不等待；快速开关不会积累采样线程。
