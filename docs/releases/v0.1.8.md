本次更新重点改善 Windows 温度采集与桌面兼容性：加入内置 CPU 温度组件，修复采集助手启动、面板点击位置和任务栏拖动排序问题，并优化诊断报告与更新入口。

## Windows 温度采集

- 新增基于 LibreHardwareMonitor 0.9.6 的内置 CPU 温度组件，支持上游已适配的 Intel / AMD 处理器，无需另行运行硬件监控软件。安装包自带 .NET 运行时。
- Windows x64 安装器新增默认选中的“CPU 温度支持”组件，使用官方签名的 PawnIO 2.2.0 安装器；保留用户取消选择的设置，跳过已安装的较新版本，并提示驱动安装失败或需要重启的情况。卸载 Tramoing 时保留共享 PawnIO 驱动。
- 温度采集在独立进程运行，提供超时恢复和自动重试；关闭温度显示后停止采集，读取失败时清除旧读数。
- 设置页按实际情况说明温度不可用的原因，包括助手未连接、组件或驱动缺失、权限不足、架构不支持等。
- GPU 继续优先使用 WDDM 驱动温度；内置读数不可用时，仍可读取已运行的 LibreHardwareMonitor / OpenHardwareMonitor 提供的 WMI 数据。

## 修复与体验改进

- 修复 Windows ETW 会话属性缓冲区不足及重启时复用系统回写属性的问题，改善采集助手启动与恢复；错误 24（ERROR_BAD_LENGTH）现在明确提示缓冲区问题。
- 修复部分 Windows OpenGL 驱动下，无边框面板绘制位置与鼠标点击位置不一致的问题。
- 任务栏温度列按实际文字宽度布局，收紧使用率与温度之间的空白，保持不同 DPI 和分组顺序下的间距一致。
- 拖动任务栏统计项排序时暂停数值刷新，避免文字宽度变化中断拖动；松开后恢复更新。
- 优化诊断报告卡片，清晰展示导出进度、保存结果与重试入口，支持直接打开文件位置及展开错误详情。
- 诊断报告补充显示缩放、窗口尺寸、显卡驱动与温度组件状态，便于定位兼容性问题；报告仍仅保存在本机，不会自动上传。
- 设置页增加 GitHub 开源仓库与手动下载更新入口；点击本机 IP 仍可复制，取消额外的复制提示。

## 下载与升级

| 设备 | 安装包 |
| --- | --- |
| Windows 10/11，Intel / AMD 64 位 | `Tramoing-0.1.8-windows-x64-setup.exe` |
| Windows 11，ARM64 | `Tramoing-0.1.8-windows-arm64-setup.exe` |
| macOS 11+，Apple Silicon | `Tramoing-0.1.8-macos-arm64.dmg` |
| macOS 11+，Intel | `Tramoing-0.1.8-macos-x64.dmg` |

每个安装包附带 SHA-256 校验文件，`latest.json` 供应用内更新。Windows 请使用完整安装包同步更新主程序、采集助手和温度组件；已有设置和历史数据会保留。

温度是否可用取决于硬件与驱动支持。Windows ARM64 以及 ARM64 上模拟运行的 x64 程序暂不使用内置 CPU 采集或安装 PawnIO 驱动，可尝试已有的 WMI 温度来源；部分旧款 AMD 处理器也暂不受内置组件支持。无有效读数时显示 `--°C`。macOS 继续使用已适配的 AppleSMC 传感器。

**macOS v0.1.4 及更早版本首次升级时，请下载 DMG 手动安装。** Windows 安装包尚未代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证。
