本次更新新增应用连接详情，方便查看程序连接的地址、端口和状态；同时调整 Windows 任务栏统计布局，改善采集超时提示、更新安装和流量统计的可靠性。

## 应用连接详情

- 点击应用行或右侧箭头，可查看当前可见的 TCP / UDP、IPv4 / IPv6 连接、本地与远端地址、连接状态和 PID。详情打开时约每 2 秒刷新，返回或收起面板后停止详情查询。
- 按本机程序、远程服务器、监听端口和本地端点分区；同协议、同目标地址和端口的记录合并为一组，展开后可查看每条记录并整组复制。只有一个地址组时首次自动展开，刷新时保留展开状态。
- 右上角说明面板提供连接统计、采集说明和应用路径复制；支持关闭按钮、点击外部或按 Esc 关闭，长内容可滚动。连接列表仅在内容超出时显示滚动条，展开、收起时保持列位置和两侧边距稳定。
- 区分“未发现连接”和“采集不完整”：系统中无法核验的进程数不代表当前应用丢失了同等数量的连接，采集不完整时显示 0 条也不能据此认定应用已退出。连接表读取错误可在说明面板的“采集详情”中查看。
- Windows UDP 仅显示系统提供的本地端点；通过代理联网时，客户端可能显示本机代理地址。列表最多显示 200 条去重记录，超过上限会提示；连接详情不写入流量历史或 CSV。

## 错误提示与采集恢复

- 短暂的采样超时先显示恢复状态，持续 30 秒未恢复才弹出提示；连接、权限和协议等明确故障仍及时提示。
- 重新整理错误弹窗的状态、详情和操作按钮。收到新的正常采样后，尚未关闭的采集提示显示“采集已恢复”，原始错误仍保留在详情和诊断报告中；历史保存失败与采集线程退出分别提示。
- Windows 温度助手消息读取超时时清除旧读数，并在下一次性能采样重试，减少短暂延迟造成的长时间读数缺失。

## Windows 任务栏显示

- 统一标签、数值、单位和温度的字号与字重，上下行保持一致。下载、上传、CPU 和 GPU 各行完整使用对应的配置颜色；关闭彩色显示时使用随任务栏深浅主题变化的中性色。
- 按实际文字宽度安排网速单位、使用率和温度，减少多余空白；统一统计组之间及温度前的间距。总宽度随内容需要调整，相同宽度的读数刷新不改变布局。
- 绘制、点击和拖拽使用同一套布局，改善不同缩放比例和统计项排列顺序下的对齐。

## 更新与统计可靠性

- 安装更新前，在后台再次校验安装包大小和 SHA-256，并保护校验到启动安装之间的文件；校验或启动失败时保留界面，显示原因并允许重试。
- 启动时清理已不需要的旧版本更新缓存，保留较新版本的待更新文件。
- 修复积压采样被记入收到数据时的秒、分钟的问题，按原采样时间回填统计，并保留原采样间隔计算网速，避免时间错位和速率被放大。
- 加强 Windows 主程序与采集助手的身份校验和通信超时处理，改善包含较长中文路径的应用识别。
- 程序已经运行时，再次以“检查更新”命令启动，会把请求交给现有实例处理。
