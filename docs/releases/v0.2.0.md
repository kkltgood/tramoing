本次更新调整语言选择和任务栏、菜单栏的显示设置，让图标、网速和性能信息可以分别控制；同时修复 macOS 升级后的启动与面板定位，并保留重启前已下载完成的更新包。

## 语言选择与界面

- 语言切换改为下拉选择，目前提供“跟随系统”“简体中文”和“English”，切换即时生效并自动保存。
- 语言名称使用各自语言显示，便于切换回熟悉的语言；下拉列表统一当前选项、悬停和选中样式。
- 界面文案改由独立翻译资源管理，后续可以扩展其他语言；本次尚未新增中文、英文以外的翻译。
- 升级时保留原有语言选择，无需重新设置。

## 独立控制显示内容

- 应用图标、实时网速和 CPU / GPU 性能信息分别提供开关，可以按需组合显示；温度仍可单独开启或关闭。
- macOS 的图标、网速和性能信息分别使用独立的原生菜单栏项，点击任一已显示的入口都可以打开主面板。
- 至少保留一个入口，避免关闭全部显示后无法再次打开设置。
- 自动迁移旧版显示配置，保留原来的显示偏好。

## macOS 启动与定位修复

- 升级完成后在后台启动，点击菜单栏入口即可打开主面板。
- 全新安装首次启动时等待菜单栏完成布局，再在入口附近展开主面板，避免使用尚未就绪的位置。
- 点击菜单栏入口时按实际点击位置和所在屏幕定位面板，改善多屏环境中的展开位置。

## 重启后恢复已下载的更新

- 更新包已经下载完成但尚未安装时，退出再打开程序会恢复待更新状态，通过校验后可直接点击“更新并重启”。
- 恢复时在后台检查文件类型、大小和 SHA-256；损坏或被替换的文件不会进入可安装状态，未完成的任务仍可手动继续下载。
- 恢复检查仅使用本地缓存，不会自动下载或安装更新，也不会阻塞界面。

## 下载与升级

| 设备 | 安装包 |
| --- | --- |
| Windows 10/11，Intel / AMD 64 位 | `Tramoing-0.2.0-windows-x64-setup.exe` |
| Windows 11，ARM64 | `Tramoing-0.2.0-windows-arm64-setup.exe` |
| macOS 11+，Apple Silicon | `Tramoing-0.2.0-macos-arm64.dmg` |
| macOS 11+，Intel | `Tramoing-0.2.0-macos-x64.dmg` |

每个安装包附带 SHA-256 校验文件，`latest.json` 供应用内更新。Windows 请使用完整安装包同步更新主程序、采集助手和温度组件；已有设置和流量历史会保留。

旧版本若仍因 `timeout: global` 无法下载，请从本发布页手动下载安装 v0.2.0。macOS v0.1.4 及更早版本首次升级时，请下载 DMG 手动安装。

Windows 安装包尚未代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证。
