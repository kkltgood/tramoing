本次更新增加 Windows 应用断网控制，重新整理设置界面和颜色选择器，并将程序、系统注册项与数据目录统一为 Tramoing。

## Windows 应用断网

- 应用列表右侧增加网络图标，点击即可断网，再次点击恢复联网；默认允许联网。
- 按程序的完整 exe 路径设置持久规则，覆盖 IPv4 / IPv6 和本机代理连接。规则跨重启保留，已断网程序即使没有流量也保留恢复入口。
- 新增“添加应用”面板，可输入完整 exe 路径，将未出现在流量列表中的程序添加并置顶；面板同时显示联网控制状态和错误提示。
- 主程序通过配套管理员助手修改规则，卸载时清理本程序创建的断网规则。请通过安装包同时更新主程序和助手。
- 多进程软件可能需要分别设置实际联网的辅助程序；程序路径变化后需重新设置。断网功能目前仅支持 Windows。

## 界面与设置

- 缩小总览网速卡片的高度，优化趋势区域、应用列表对齐、置顶图钉和工具按钮。
- 设置页依次为“任务栏 / 菜单栏 → 统计 → 通用”。首次进入显示任务栏或菜单栏设置，之后保留本次运行中选择的页签，各页签分别保留滚动位置。
- 收紧分组与选项间距，统一左侧标签和开关对齐；自动保存提示移到标题右侧，版本号和检查更新入口集中到“通用 → 启动与更新”。
- 下载、上传、CPU、GPU 的色块、色值输入框和默认按钮统一高度并垂直居中。
- 重做选色面板：提供饱和度与亮度取色区、色相滑条、常用色、HEX 输入和 RGB 预览，支持深浅主题、中英文、键盘微调和恢复默认。
- 颜色调整即时生效；无效或尚未输入完整的色值不会覆盖原颜色。

## 命名、迁移与可靠性

- 当前程序标识、数据目录、采集助手任务和安装脚本统一使用 Tramoing；旧名称仅保留在升级兼容代码中。
- 首次启动迁移旧设置、历史和待写入记录，保留旧目录作为备份，不覆盖新目录已有文件；同步迁移登录自启项并清理旧助手任务。
- 修正 macOS TCP / UDP 端点归属混淆，采集退出时继续处理最后一帧，改善转发流量的统计一致性。
- 历史累计和数据库聚合加入溢出保护，兼容旧溢出记录；CSV 导出转义可能被表格软件当作公式的字段，导出失败返回非零退出码。

开启代理时，Windows 外网流量仍可能统计到代理进程，例如 verge-mihomo。本次更新未改变这一统计归属限制。

## 下载与升级

- Windows 10 / 11 x64：`Tramoing-0.1.5-setup.exe`。
- macOS 11+，Apple Silicon / Intel：通用包 `Tramoing-0.1.5.dmg`。
- 两个安装包均附带 SHA-256 校验文件，`latest.json` 用于应用内更新。

**macOS v0.1.4 及更早版本首次升级到 v0.1.5 时，请下载并打开新版 DMG 手动安装。** 此版本更新了应用标识，旧客户端会拒绝自动替换为新标识的应用。新版安装器可识别旧安装，首次启动会迁移设置和历史数据。

Windows 安装包尚未进行代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证。
