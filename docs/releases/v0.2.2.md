Windows x64 的内置温度采集改为按需安装，基础安装包更小。需要温度读数时，可在性能设置中下载缺失的组件。

## 安装与升级

- 开启温度显示后，在性能设置中点击“下载所需组件”。程序会检查温度组件、x64 .NET 运行时和 PawnIO 驱动，显示需要下载的大小。下载并校验完成后，点击“安装并启用”。
- 从 v0.2.1 升级时可继续使用完整、兼容的旧版温度组件及其自带运行时。程序也能识别已安装的兼容系统运行时和驱动，只补齐缺失或损坏的部分。
- 新安装使用独立发布的 Windows x64 温度组件 1.0.0。Windows ARM64 继续使用系统提供的温度数据。[温度组件发布页](https://github.com/kkltgood/tramoing/releases/tag/sensors-v1.0.0)

## 下载与显示

- 组件下载可暂停和继续。重启程序或点击“重新检查”后，完整且校验通过的缓存可直接安装，未完成的下载会显示已保存的进度。
- .NET 运行时和 PawnIO 优先从官方来源下载，失败时可切换至备用来源。续传片段校验失败时，程序会丢弃损坏的数据并重新下载。
- 性能设置分栏显示 CPU 和 GPU 的使用率及温度。Windows 温度组件的安装状态和操作按钮显示在读数下方。
