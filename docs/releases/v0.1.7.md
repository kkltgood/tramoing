本次更新加入本机 IP 显示、设置页切换动画、CPU/GPU 温度，以及无需命令行的错误诊断与日志导出。

## 新功能与体验改进

- 主面板底部居中显示当前网络的本机 IP，每 5 秒自动刷新，点击即可复制。更新提示和导出结果不会遮住地址。
- 设置页 Tab 的选中背景平滑滑动，内容随切换方向淡入，各页保留独立的滚动位置。
- CPU/GPU 使用率旁可选显示温度；“显示温度”独立开关会保存，关闭时停止温度采集。
- 改进应用置顶、受限应用恢复入口与列表名额分配，统一 Windows 路径大小写识别，避免重复应用或置顶顺序异常。

## 错误提示与日志导出

- 运行出错时弹框询问是否导出日志，完成后可直接打开文件位置；同一来源和内容的重复错误在 5 分钟内合并。
- 主窗口启动失败时提供原生弹框；Rust 崩溃先保存日志，再尝试启动独立报告进程。无法启动报告进程时，保留提示供下次打开。
- 新增设置中的“日志与故障反馈”入口，采集异常页面也可直接导出。导出在后台执行，不要求用户使用命令行。
- 主程序和 Windows 采集助手统一使用有大小限制、自动轮换的日志，记录版本、系统、错误上下文与可获得的 panic 回溯。
- 诊断报告包含系统、采集助手状态和最近日志，不含流量数据库；仅保存在本机，不会自动上传。导出前需用户确认。

## 下载与升级

| 设备 | 安装包 |
| --- | --- |
| Windows 10/11，Intel / AMD 64 位 | `Tramoing-0.1.7-windows-x64-setup.exe` |
| Windows 11，ARM64 | `Tramoing-0.1.7-windows-arm64-setup.exe` |
| macOS 11+，Apple Silicon | `Tramoing-0.1.7-macos-arm64.dmg` |
| macOS 11+，Intel | `Tramoing-0.1.7-macos-x64.dmg` |

每个安装包附带 SHA-256 校验文件，`latest.json` 供应用内更新。Windows 请使用安装包同时更新主程序和采集助手；已有设置和历史数据会保留。

温度是否可用取决于硬件与驱动。macOS 使用已适配的 AppleSMC 传感器；Windows GPU 优先使用 WDDM 驱动读数，CPU 需要已运行并提供 WMI 数据的 LibreHardwareMonitor 或 OpenHardwareMonitor。无可用读数时显示 `--°C`，不会自动安装第三方监控工具或驱动。

**macOS v0.1.4 及更早版本首次升级时，请下载 DMG 手动安装。** 强制终止、断电和部分原生崩溃可能无法触发错误提示。Windows 安装包尚未代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证。
