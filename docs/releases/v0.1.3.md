本次更新集中优化安装和升级体验，保留已有设置、历史记录及自启配置。

- Windows 升级自动识别已有安装目录，跳过目录、组件和完成页，只显示更新进度，完成后自动重新打开。旧客户端直接打开新安装包也能识别升级。
- Windows 应用内更新等待程序保存历史并退出后再替换文件；取消系统授权或启动失败时保留下载包，支持重试。
- macOS 从 DMG 打开应用后提供“安装并打开”或“更新并打开”，自动选择安装位置，并显示原生安装进度；首次运行会展开面板，帮助找到菜单栏入口。
- macOS 应用内更新在后台校验并准备新版本，再退出、替换完整应用并重新打开；替换或打开请求失败时尝试恢复旧版本。
- macOS DMG 增加双语安装说明、Applications 快捷入口、拖拽指引和 Retina 背景，支持 Apple Silicon 与 Intel。
- 增加 Windows 升级回归验证和 macOS 安装包完整性、签名及布局检查，并补充安装、更新与故障排查文档。

Windows 10/11 x64 下载 `Tramoing-0.1.3-setup.exe`；macOS 11+ 下载通用包 `Tramoing-0.1.3.dmg`。安装包均附带 SHA-256 校验文件，`latest.json` 用于应用内更新。

旧版 macOS 客户端首次升级到此版本时，仍可能先打开 DMG；运行其中的 Tramoing 后即可使用新的安装流程。安装此版本后的后续更新使用新的应用内流程。

Windows 安装包尚未进行代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证，系统可能仍会显示来源或安全提示。
