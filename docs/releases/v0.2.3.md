从 v0.2.3 起，Tramoing 检查到适合本机的新版后会在后台下载安装包。下载完成不等于立即重启：校验通过后，由你决定何时安装。

## 应用内更新

- 安装包通过 SHA-256 校验后，可选“重启并更新”或“下次启动时更新”。选择下次启动时，程序会在本机重新校验安装包，只尝试安装一次；没有做出选择时不会自行安装。
- 下载失败后最多自动重试 8 次。下载时意外退出，下次启动会从已有进度继续，沿用剩余重试次数。手动暂停、重试耗尽或旧版留下的不完整下载需要手动继续。
- 自动重试耗尽后，可以查看错误详情、继续下载，或打开该版本的发布页手动下载安装包。
- 在“设置 → 通用 → 启动与更新”可查看上次检查的本地时间和结果。即使重启也会保留记录；旧版只记录了时间的检查不会被显示为成功。

## Windows 温度组件

- 修复 x64 温度组件可能将不完整或架构不匹配的 .NET 运行时识别为可用的问题。
- 修复组件下载切换来源时的一种重复下载：如果服务器不支持续传，返回的完整文件又未通过校验，程序会尝试下一来源，而不是从同一地址再下载一次。

## 下载

| 设备 | 安装包 |
| --- | --- |
| Windows 10/11，Intel / AMD 64 位 | `Tramoing-0.2.3-windows-x64-setup.exe` |
| Windows 11，ARM64 | `Tramoing-0.2.3-windows-arm64-setup.exe` |
| macOS 11+，Apple Silicon | `Tramoing-0.2.3-macos-arm64.dmg` |
| macOS 11+，Intel | `Tramoing-0.2.3-macos-x64.dmg` |

每个安装包附带 SHA-256 校验文件，`latest.json` 供应用内更新。
