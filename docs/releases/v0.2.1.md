本次更新修复 Windows 部分设备 CPU 有温度、GPU 没有温度的问题，并减少升级或卸载后留下重复托盘图标的情况。

## Windows GPU 温度

- WDDM 驱动没有返回 GPU 温度时，尝试通过内置 LibreHardwareMonitor 读取显卡传感器；NVIDIA 使用 NVAPI，无需另开第三方监控软件。
- CPU 和 GPU 分别处理读取结果，单个显卡读取失败不会清除其他有效温度；GPU 初始化失败会稍后重试。
- CPU 和 GPU 已有有效读数时停止额外的 WMI 查询，并在诊断报告中标明 GPU 温度来源及采集失败状态。
- 内置 GPU 采集沿用 Windows x64、管理员采集助手及 PawnIO 的前置条件。温度仍取决于硬件和驱动支持，不可用时显示 `--°C`；ARM64 继续使用可用的 WDDM/WMI 来源。

## Windows 托盘图标

- 安装升级和卸载时先请求旧主程序正常退出，等待托盘清理和历史保存，超时才强制结束进程。
- 主程序退出时提前移除托盘图标，减少等待后台线程期间产生残留的机会。
- 已经由旧版本留下的 Explorer 残影不会被新程序主动删除；如果任务管理器中只有一个 `tramoing.exe`，可将鼠标移过旧图标促使刷新。

| macOS 11+，Apple Silicon | `Tramoing-0.2.1-macos-arm64.dmg` |

每个安装包附带 SHA-256 校验文件，`latest.json` 供应用内更新。Windows 请使用完整安装包同步更新主程序、采集助手和温度组件；已有设置和流量历史会保留。

Windows 安装包尚未代码签名；macOS 使用 ad-hoc 签名，尚未进行 Developer ID 签名及公证。
